Warehouse Shelving Systems

Warehouse shelving systems work best when shelf locations, picking tasks and replenishment are planned together. Start with the order profile and the containers people handle.

Published by zhengdarack · Updated 14 November 2026

Plan Your Rack Specification →
The short answer

A warehouse shelving system combines storage units with the way stock is assigned, replenished and picked. Static shelves, divided bins and carton-flow lanes suit different item and movement patterns. Specify the picking unit, its dimensions and weight, the quantities needed at each location and the route used to refill it.

What information should you collect before planning shelving?

Start with the unit that a person actually picks: one part, a small pack, a carton or a full container. The inbound delivery unit may be different. A pallet arriving at receiving does not mean the picking area needs pallet-sized locations.

  • Item profile: dimensions, weight, packaging and whether the contents need a bin or divider.
  • Order profile: items picked together, quantities per order and peak activity.
  • Replenishment: source location, container size, frequency and who performs it.
  • Control needs: batch separation, product identification, returns and any restricted stock.

Keep the largest, heaviest and most frequently picked items visible in the brief. An average carton can hide the exceptions that determine shelf openings or handling requirements. For individual shelf construction and surfaces, use the industrial shelving selection guide.

Interlake Mecalux's carton-flow description explains the use of inclined rollers and separate stocking and picking faces. Treat that operating principle as a starting point; packaging condition, lane setup and the proposed product range still need application checks.

You can compare a mixed arrangement without assuming every SKU needs the same storage medium. Ask how locations transfer between categories if demand or packaging changes. Keep any quoted performance claims tied to the supplier's stated conditions.

How should replenishment connect to the picking area?

A picking location needs enough stock for its agreed refill process, not merely enough room for one carton. Define when a refill is triggered, where the replacement stock comes from and how the transfer is confirmed. The shelf layout should make that process visible.

As an illustration, if a location holds 12 cartons and 3 are picked before the next planned refill, 9 remain. This is only a stock movement calculation. It does not account for a demand spike, late replenishment, carton dimensions or shelf capacity. Test those conditions separately before assigning a target quantity.

Check where refill containers and empty packaging wait. If those items occupy the same route used for picking, the nominal shelf plan may understate the working space needed. Include both tasks in the trial rather than reviewing an empty aisle.

How do you organise labels, bins and item locations?

Give each storage location an identifier that remains clear when stock changes. For example, a locally defined code can identify an aisle, bay, level and position. Document the meaning and use it consistently on labels and stock records.

  1. Define the location: mark the physical position before allocating an item.
  2. Identify the stock: show the item reference and any required batch information.
  3. Test visibility: view the label with the normal container in place.
  4. Control exceptions: provide a defined place for returns or unidentified goods.
  5. Update records: record relocation before relying on the new position for picking.

Similar-looking items deserve particular attention during the trial. Check whether packaging or a container hides the identifying details. A divided shelf can separate goods physically, but the labels and inventory records still need to match the allocation.

What should a small shelving trial verify?

Use representative cartons, containers and order tasks. Record observations rather than promising a percentage productivity improvement without measurements.

  • Can the picker identify and withdraw the required item?
  • Can the refill task occur without an unresolved conflict with picking?
  • Do the largest containers fit the usable openings and labels?
  • Are exceptions, empties and returns kept in defined places?
  • Do the load assumptions match the actual contents of the shelves?

The HSE manual-handling overview provides background on assessing handling tasks. A storage capacity does not by itself establish a suitable lifting or reaching task. Include the handling aids and people involved when reviewing the proposed arrangement.

For a larger warehouse, connect the trial with the overall storage and working-area plan. Record what must change before repeating the arrangement across more bays.

Warehouse shelving systems: common questions

How is a shelving system different from an individual shelf?

The system includes storage units, location allocation, replenishment and picking. A shelf can fit the carton while the overall process still needs changes to routes, quantities or labels.

Should all products have the same-sized location?

Not necessarily. Compare item dimensions, quantities and picking needs. Standard locations can simplify allocation, but exceptions should be identified rather than forced into unsuitable spaces.

Does carton flow work with every box?

No assumption should be made from the product name alone. Request checks using the actual carton sizes, weights, bases and packaging condition on the proposed lane arrangement.

Can shelving and pallet reserve storage work together?

Yes. Define how stock moves from the reserve location to the pick shelf, including refill quantities, equipment, routes and inventory confirmation.

What information should a supplier return?

Ask for the location layout, usable shelf openings, load assumptions, component quantities and a description of the picking and replenishment arrangement being proposed.
